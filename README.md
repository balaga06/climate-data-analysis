# Global Climate Data Analysis

## Overview

This project performs Exploratory Data Analysis (EDA) on a **Global Weather Repository** containing over **164,000 weather records**. The project cleans, analyzes, and visualizes climate data using Python.

## Dataset

* **Records:** 164,499+
* **Features:** 41
* **Size:** ~42 MB

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn

## Visualizations

* Temperature Trend
* Temperature Distribution
* Humidity Distribution
* Wind Speed Distribution
* Temperature vs Humidity
* Correlation Heatmap
* Top 10 Hottest Countries
* Top 10 Most Humid Countries
* Monthly Average Temperature
* Weather Condition Analysis

## How to Run

```bash
pip install -r requirements.txt
python climate_data_analysis.py
```
